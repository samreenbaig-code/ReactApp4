# React Voting App (ReactApp4)

## 📌 Description
This is a reusable voting application built using React and TypeScript.  
Users can vote on different items and see real-time updates.

---

## 🚀 Features
- Reusable components (VoteItem, VoteList, Header)
- Global state management using Context API
- Voting system with live updates
- Unit testing using Vitest and Testing Library
- Local storage to save votes
- Add new voting items dynamically
- Progress bar and percentage display
- Dark mode toggle
